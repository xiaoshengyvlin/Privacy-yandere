# 想了解你

一个受 [taken.](https://sinceyouarrived.world/taken) 启发的病娇风浏览器隐私演示页面。

你打开它，回答一些看似无害的问题。它则在暗处收集你的浏览器指纹——屏幕、设备、语言、时区、显卡、字体、电量、IP 地址——然后在一句句病娇的低语中，把这些信息逐层返还给你。最后一页会显示你的城市和完整设备档案。

> 本页面没有向任何第三方发送数据。所有信息仅在浏览器中处理，关闭后即遗忘。

## 技术实现

纯前端单文件，无框架，无构建工具。包含：

- **浏览器指纹收集**：User-Agent 解析、WebGL GPU 检测、字体探测（17种）、屏幕尺寸与像素比、`navigator` API 全套
- **IP 地理定位**：通过 `ipapi.co` / `ip-api.com` 免费 API 获取城市/ISP
- **设备姿态检测**：`DeviceOrientationEvent`、`screen.orientation`、电池 API、存储估计
- **行为追踪**：页面停留时长、滚动深度、切标签次​数+离开时长、鼠标移动次数、点击次数、滚动停顿检测（仅显示，不发送）
- **隐私偏好读取**：Do Not Track、`prefers-reduced-motion`、`prefers-color-scheme`

## 设计理念

问题从正常到病娇分 11 步递进：

1. **Q1–Q4**：纯闲聊，建立信任
2. **Q5**：钩子——"你容易被看透吗？"
3. **Q6**：首次揭示——时间和时区
4. **Q7**：设备 + 屏幕分辨率 + 像素比
5. **Q8**：语言偏好 + 暗色模式
6. **Q9**：硬件指纹（GPU、字体、DNT、动效、陀螺仪）
7. **Q10**：行为痕迹（来路、Cookie、电量、存储空间）
8. **Q11**：位置炸弹——城市、ISP、IP 地址

每步揭示的信息量逐级递增，病娇感也随之加深。
